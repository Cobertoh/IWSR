# IWSR Tool

An all-in-one speedrun tool for Call of Duty: Infinite Warfare Zombies.

**[⬇ Download the latest version](../../releases/latest)** · [Discord](https://discord.gg/rf5QVDy3kP)

## What's in it

- In-game timer with splits and auto splits (works with LiveSplit)
- Card loadouts
- Animated camos
- Frame cap up to 240 fps
- Unlock all (nothing is saved to your account)
- Special characters for every map
- Map restart key
- One-click start

## Install

1. Download `IWSR_TOOL_vX.X.zip` from the **[Releases page](../../releases/latest)** and unzip it.
2. Copy `IWSRToolLoader.exe` and the `IWSR` folder into your game folder:
   `...\Steam\steamapps\common\Call of Duty - Infinite Warfare\`
3. Run `IWSRToolLoader.exe`. It starts the game and loads the tool.
4. Open **IWSR** from the pause menu or the zombies main menu.

The full guide is `IWSR\README.txt` in the download.

> Windows or your antivirus may warn about `IWSRToolLoader.exe`. It's a false alarm: the loader injects the tool into the game, which is how it works. Only download the tool from this page or the official IWSR Discord.
